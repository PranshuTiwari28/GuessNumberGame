# 🎯 Guess My Number

A simple browser game where you try to guess a secret number between 1 and 20.

🔗 **Live Demo:** [pranshu-tiwari-guess-number.netlify.app](https://pranshu-tiwari-guess-number.netlify.app/)

## ✨ Features

- Guess the secret number between 1 and 20
- **Check!** button to submit your guess
- Score tracking, starting at 20
- Highscore tracking
- **Again!** button to start a new round

## 🚀 Run Locally

```bash
git clone https://github.com/PranshuTiwari28/GuessNumberGame.git
cd GuessNumberGame
```

Then open `index.html` in your browser.
